# Avinash IT Admin Toolbox – Web Edition

Browser-friendly companion to the Python/Tkinter Windows desktop app.

## Features
- System/browser diagnostics
- Network connection information
- DNS and reverse DNS lookup
- IPv4 subnet calculator
- Website reachability check
- Secure password generator
- SHA256 hashing
- SSH URI helper
- Diagnostic output copy/export

## GitHub Pages
Enable GitHub Pages under **Settings → Pages → Deploy from a branch → main → / (root)**.

> Browser security prevents direct ICMP ping, arbitrary TCP port scans, Windows PowerShell/CMD, mstsc.exe execution and local MAC/adapter enumeration. Use the desktop edition for native Windows administration features.
